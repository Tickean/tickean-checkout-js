Tickean Elements v0.2 · demo mode

Vanilla checkout

Carga @tickean/checkout-elements con transport demo in-memory (sin backend). Desde la raíz del monorepo: 

npm install
npm run build
npm run start -w vanilla-elements
# → http://localhost:3011

Si actualizás el código fuente, volvé a ejecutar npm run build antes de recargar.
